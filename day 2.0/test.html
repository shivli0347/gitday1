Bash Commands I have learnt

1.Touch

File creation

The touch command creates a new, empty file. If the file already exists, it simply updates the file's last-modified timestamp instead of changing its content. It's one of the simplest ways to create a file directly from the terminal.

Syntax: touch filename

Example: touch notes.txt

Output: (no output - the file notes.txt is created silently in the current folder)

2.mkdir

folder creation

The mkdir command creates a new, empty folder (directory) at the location you specify.

Syntax: mkdir foldername

Example: mkdir project

Output: (no output - the folder project is created in the current directory)

cd

changing directory

The cdcommand changes the current working directory,moving you into a different folder in the terminal.

syntax:cd foldername

example: cd project

Output:(prompt change to show you are now inside ~/project)

My understanding: grep searches through the contents of a file (or files) for lines that match a given word or pattern, and it prints out only the matching lines rather than the whole file. This makes it useful for quickly finding where a particular word or piece of text appears inside a large file without having to open and read it manually.
